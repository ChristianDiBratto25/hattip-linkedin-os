# Acceptance tests

Run these manually in Claude Code using a test workspace:

1. New user says `Start my LinkedIn strategy`: asks conversational questions; does not prematurely generate a calendar; saves faithful onboarding; confirms details.
2. Strategy: exactly 3 to 4 buckets per stage, explicit ICP and why each bucket exists; rationale for funnel allocation; no generic unrelated topics.
3. Ideas: 20 differentiated angles with reference URLs only from actual reference records or verified live results; monthly scheduled count fits user cadence; no fake evidence.
4. Write: requests real material, creates CPIO plan, gets necessary approvals, delivers readable distinct draft with media choice.
5. Review: weak packaging triggers RETHINK; minor prose issues trigger REVISE; sound post triggers PASS; preserves voice and no invented claims.
6. Weekly: extracts ideas from specific supplied experiences and checks duplicates.
7. Research: with no browsing, explicitly states limitation; with browsing, uses dated sources and avoids unsupported claims.
8. Performance: given a tiny CSV, reports small sample limitation and avoids false causal inference.
9. Privacy: local workspace is gitignored. No user data in public reference files.
10. All outputs: no em dashes, AI slop, manufactured urgency, forced sales pitches or unsolicited source-tracker documents.
