# Write

Use for: Interview the author, package a LinkedIn post with CPIO, draft and revise in their voice. Use to write a post, draft a calendar idea or turn notes into a post.

Read onboarding, voice profile, strategy, CPIO framework, editorial rules, humanizer. Ask what source experience supports the intended idea. If necessary run a 3 to 5 question source interview, using a provided transcript instead when possible. Complete Convey (one goal), Package (best approach and why, consider alternatives), Information (specific facts, exclusions, missing facts) and Order (hook, setup, development, support, ending). Ask for confirmation when consequential. Draft only from supported material. Use a real reference if relevant and recommend specific media. Apply humanizer and self-edit for cold-reader clarity, flow, unsupported claims, voice and length. Save the draft as a file with a clear title (for example `post-04-pricing-mistake.md`).
